# 제품 이미지 폴더

이 폴더에 제품 사진, 로고, 2단 케이크 사진을 업로드합니다.

파일명은 영문 소문자, 숫자, 하이픈 사용을 권장합니다.

예시:

- `peach-yogurt.png`
- `strawberry-cake.png`
- `two-tier-cake.png`
- `harehare-logo.png`

이미지 주소 형식:

```text
https://raw.githubusercontent.com/harebakery-cmd/cake-menu/main/public/images/파일명.png
```
